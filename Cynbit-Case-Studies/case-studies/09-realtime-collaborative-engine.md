## Client need

The client needed reliable simultaneous editing for a cloud-based writing platform.

## Challenge

Users experienced significant lag and document conflicts when multiple writers attempted to edit simultaneously.

## Solution

Cynbit refactored the communication layer using optimized WebSockets and Conflict-free Replicated Data Types (CRDTs).
